Политика конфиденциальности
1. Какие данные мы собираем
Бот собирает и обрабатывает только те данные, которые необходимы для работы функционала:

Discord ID пользователя (числовой идентификатор) — нужен для привязки баланса, истории наказаний, выдачи ролей и т. п.
Имя пользователя и аватар (через API Discord) — для отображения в профилях, топ‑листах, логах.
ID сервера и каналов — для работы команд в нужных каналах, выдачи авторолей, отправки логов.
Текстовые сообщения, которые пользователь отправляет боту или в каналы, где бот имеет доступ к содержимому (если включено message_content).
Данные голосовых каналов (при необходимости музыки): факт нахождения пользователя в канале, подключение к каналу.
Локальные файлы (если команда предполагает анализ файла) — обрабатываются только в оперативной памяти и не сохраняются на диск без явного указания в коде.
2. Для чего используются данные
Исполнение команд (экономика, модерация, музыка, мини‑игры).
Ведение балансов и истории транзакций.
Модерация (кик, бан, мут, логирование нарушений).
Автовыдача ролей и приветственные действия.
Формирование статистики и топ‑листов.
3. Хранение и срок хранения
Базы данных (economy.json, punishments.json, server_log.json) хранятся на сервере, где запущен бот.
Данные хранятся столько, сколько необходимо для функционирования бота. Пользователь может запросить удаление своих данных у администратора сервера.
При удалении бота с сервера администратор может вручную удалить локальные файлы баз данных.
4. Передача третьим лицам
Данные не передаются третьим лицам, кроме случаев, прямо предусмотренных законодательством.
Бот не отправляет данные в сторонние сервисы, не ведёт телеметрию и не использует рекламные сети.
5. Безопасность
Файлы баз данных хранятся в той же директории, что и код бота. Доступ к ним должен быть ограничен правами ОС.
Токен бота никогда не сохраняется в файлах и не отображается в логах. Используйте переменные окружения.
Не храните чувствительные данные (имена, телефоны, адреса) — бот для этого не предназначен.
6. Права пользователя
Пользователь вправе:

Запросить у администратора сервера удаление своих данных.
Отказаться от использования бота, покинув сервер или не взаимодействуя с ним.
Сообщить об ошибке или нарушении через администратора сервера.
7. Изменения политики
Изменения публикуются в описании бота или на странице проекта. Продолжение использования бота после публикации изменений означает согласие с обновлённой версией.

Правила использования (User Policy / Terms of Use)
1. Кто может пользоваться
Использование бота разрешено участникам сервера, на котором он установлен, при условии соблюдения правил сервера и настоящих Правил.

2. Разрешённое использование
Разрешено:

Использовать команды бота в соответствии с их описанием.
Участвовать в мини‑играх и экономике.
Получать роли и бонусы, предусмотренные функционалом.
3. Запрещённое использование
Запрещено:

Использовать бот для спама, флуда, массовых упоминаний, вредоносных ссылок.
Обходить муты и блокировки, использовать эксплойты, автоматизировать команды с целью нарушения правил.
Пытаться получить доступ к чужим балансам, истории наказаний или иным данным других пользователей.
Использовать функционал модерации не по назначению (например, мутить без причины).
Загружать файлы, содержащие вредоносный код, запрещённый контент, персональные данные третьих лиц.
Распространять токен бота, ключи доступа, исходные файлы с токенами.
4. Модерация и ответственность
Решения о наказаниях принимают администраторы сервера с использованием команд бота.
История наказаний хранится для прозрачности и может быть показана по запросу администратора.
Нарушение Правил может привести к ограничению доступа к командам бота или блокировке на сервере.
5. Экономика и игры
Все игровые механики носят развлекательный характер и не являются азартными играми в юридическом смысле.
Выигрыш/проигрыш в мини‑играх не подлежит денежной компенсации.
Администрация оставляет за собой право обнулить баланс или аннулировать транзакции при выявлении мошенничества.
6. Изменения и прекращение работы
Функционал бота может изменяться или отключаться без предварительного уведомления.
Администратор сервера может в любой момент удалить бота с сервера.# XIVIBE
